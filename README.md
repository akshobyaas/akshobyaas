## 🚀 Featured Projects

### ⛽ [PitLog — Vehicle Fuel & Service Tracker](https://github.com/akshobyaas/fuel-service-tracker) &nbsp;·&nbsp; [**Live ↗**](https://ak-pitlog.vercel.app)

An installable PWA for bike and car owners to log fill-ups, track tank-to-tank mileage, manage service history, and get alerts before documents expire.

- Email-OTP registration and login, with expiry, attempt lockout and resend cooldown
- Per-user document storage on Backblaze B2 (S3-compatible), with expiry status tracking
- Chart.js analytics: mileage trends, monthly cost, cost per km, service breakdown
- PWA with offline fallback, WCAG 2.1 AA accessibility, dark/light/auto themes, CSV export
- Custom `manage.py check` warnings that catch unsafe production config

`Django 5.2` `PostgreSQL` `Backblaze B2` `Chart.js` `WhiteNoise` `PWA`

### 🖥️ [ISHMS — Intelligent System Health Monitoring](https://github.com/akshobyaas/ishms)

A real-time telemetry dashboard that samples CPU, memory, temperature and power every 2 seconds, flags anomalies, and diagnoses the likely cause (memory leak, overheating, power spike…).

- Live dashboard with real-time charts, anomaly history and CSV export
- scikit-learn model plus a rule-based root-cause engine with confidence scores
- REST API for live data, history, manual tests and offline CSV analysis

`Django` `Python` `scikit-learn` `pandas` `psutil` `Chart.js`
